# MCP Server Workspace

This repository contains three separate projects:

- [local-mcp-server](local-mcp-server/README.md) for the local desktop MCP server
- [cloud-mcp-server](cloud-mcp-server/README.md) for the cloud relay server
- [local-tool-service](local-tool-service/README.md) for the desktop-side relay client

The repo-level docs under [docs/](docs/) describe the architecture, hosting, and multi-device flow.

If you want to run the local MCP server, start in [local-mcp-server](local-mcp-server/README.md).
